# Achar & Co. — Pickle Store Website

A responsive front-end website starter for a Kerala-inspired pickle business.

## Included
- Home, About, Services, Products, Customer Reviews and Contact sections
- Responsive desktop and mobile navigation
- Product category filters and search
- Pack-size price selection
- Shopping cart with quantity controls and localStorage persistence
- Build-your-own 3-jar combo
- Demo review form, contact form and newsletter form
- Responsive layout and reduced-motion support

## Run locally
No build tools are required.

1. Extract the ZIP folder.
2. Open `index.html` in a browser.

For a local development server (optional):
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Important: replace sample content before launch
Open `index.html` and `app.js` and update:
- Brand name and logo
- Product names, descriptions, pack sizes and prices
- Product and brand photographs
- Phone number, email, location and WhatsApp link
- Sample customer reviews with genuine customer feedback

## Demo limitations
This is a front-end prototype. Cart data is stored in the browser only. Contact, newsletter and review forms do not send data to a business inbox or database. Checkout does not take payment. Connect a backend, WhatsApp ordering, payment provider and order management before accepting real orders.

## Image note
The sample photos are loaded from Unsplash using remote image URLs, so an internet connection is required for those images to display.
